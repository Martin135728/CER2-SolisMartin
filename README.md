# Fundación Patrimonio Vivo - Certamen 2

Aplicación web desarrollada en **Django**, en conjunto con **Bootstrap 5** para identificar, documentar y difundir lugares de interés patrimonial en Chile.

## Requisitos Previos
Tener instalado en el sistema:
- Python (versión 3.10 o superior recomendada)

---

## Instrucciones de Instalación y Configuración

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Martin135728/CER2-SolisMartin.git
   cd CER2-SolisMartin/Certamen2

2. **Instalar las Dependencias:**

  pip install -r ../requirements.txt

3. **Configurar la Base de Datos:**

  python manage.py migrate

---

# **Ejecución de la Aplicación**

   Ejecutar el comando:

   python manage.py runserver o py manage.py runserver

   _Una vez iniciado, se ingresa a la web por la dirección dada_.
